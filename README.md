# Active-Directory-Home-Lab
Enterprise-style Active Directory home lab featuring Windows Server, Windows clients, Kali Linux, network segmentation, penetration testing, detection, and defensive hardening.

## Objectives
- Build a realistic Windows domain
- Learn Active Directory administration
- Practice penetration testing
- Simulate enterprise attacks
- Implement defensive controls
- Develop incident response skills

## Technologies
- Windows Server 2022
- Windows 11
- Kali Linux
- VMware Workstation Pro
- PowerShell
- Bash

- BloodHound
- SharpHound
- Impacket
